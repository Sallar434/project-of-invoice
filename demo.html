            How the follow-up works

            1. Add an invoice

              Reference, client, currency, total, due date, and what has already been paid. DueTrail does not create the invoice in your accounting tool.

            2. Record the payment context

              Who can actually approve payment, which submission steps are still open, and the date they promised.

            3. Copy a reminder and log the outcome

              Edit the draft, copy it, and send it yourself. Then log a promise, a partial payment, a dispute, or paid in full.

            Questions worth answering first

            Does this replace my invoicing tool?

            No. Track invoices you already create elsewhere. DueTrail is the follow-up desk, not QuickBooks, Wave, or a ledger.

            Does it send messages?

            Not in this prototype. You review and copy the text, then send it yourself. Nothing is emailed or messaged automatically.

            Where is demo data stored?

            In this browser only. Use sample data. Browser storage is not a secure, backed-up financial system, and it is not audit-grade evidence.

            Will this get the invoice paid?

            No. Software can show the next useful step. It cannot make an unwilling or insolvent client pay, and DueTrail does not promise recovery.

            What this demo will not do

            DueTrail is made by Sallar Hussain Bali. The name is not a cleared trademark. There is no account, bank connection, payment form, debt collection, or automatic reminder. On a phone, the browser menu can install this demo to the home screen. That copy still stores data only on the device. Reset sample data if you want the fictitious workspace back.
